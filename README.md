# Financial Modeling & Portfolio Analysis Projects

This repository contains Python-based finance projects focused on portfolio returns, diversification, risk analysis, mean-variance efficiency, and applied financial modeling.

## Projects Included

### Portfolio Return Analysis
Built a buy-and-hold portfolio using AAPL, MSFT, TSLA, and KO. The project calculates fractional shares, daily log returns, portfolio weights, cumulative portfolio returns, and portfolio value over time. :contentReference[oaicite:0]{index=0}

### Diversification Effect
Analyzed how portfolio risk changes as more stocks are added. The project uses monthly returns, ranks stocks by volatility, creates equally weighted portfolios, and shows how diversification reduces overall volatility. :contentReference[oaicite:1]{index=1}

### Risk Analysis
Compared AMZN and AAL using daily log returns, variance, 45-day rolling volatility, and EWMA volatility. The analysis highlights volatility clustering and the stronger COVID-period volatility impact on AAL. :contentReference[oaicite:2]{index=2}

### Mean-Variance Efficiency of the S&P/TSX 60 (XIU)
Reconstructed XIU returns using constituent weights, analyzed tracking correlation, tested diversification across multiple stocks, and generated random portfolios to compare risk-return efficiency and Sharpe ratios. :contentReference[oaicite:3]{index=3}

### Portfolio Management
Built a full portfolio management workflow using assigned S&P 500 tickers, Yahoo Finance data, Fama-French factors, firm-level metrics, market capitalization, liquidity, beta estimation, momentum strategy, portfolio holdings, benchmark comparison, alpha, Sharpe ratio, and Treynor ratio. :contentReference[oaicite:4]{index=4}

### Financial Modeling Grand Project
Completed broader financial modeling exercises including mortgage amortization, lease depreciation analysis, retirement planning with Monte Carlo simulation, and fund construction using Sharpe-ratio optimization versus random allocation. :contentReference[oaicite:5]{index=5}
